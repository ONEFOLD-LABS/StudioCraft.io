AI agents & MCP

Let an AI agent produce with you.

studiocraft-cli mcp exposes StudioCraft through the Model Context Protocol. Agents such as Claude Code, Claude Desktop, Codex or Cursor create projects, edit them, save them and render mixdowns.

Set up{{icon:arrow}} Full documentation{{icon:external}}

Two modes

Headless or in the running app.

In both cases the tools run through the same code as the app: undo history, import, saving and mixdown behave exactly the same.

headless · default

A project without a window

The server keeps its own project window in memory – without a screen and without an audio device. Ideal for scripts and automation.

Terminal
studiocraft-cli mcp \
  --automation-read-root ~/Music/Samples \
  --automation-write-root ~/Music/Projects

--connect

The agent works in your app

The app opens a local control channel with its own token. You see every change immediately and can undo it with Ctrl+Z.

Two terminals
studiocraft --control 7850
studiocraft-cli mcp --connect 7850 \
  --automation-read-root ~/Music/Projects \
  --automation-write-root ~/Music/Projects

Setup

Connected in a minute.

Register the MCP server in your client once – done. Errors and notices go to stderr; stdout carries protocol messages only.

Tools

What an agent can do.

Positions count like the ruler (5.1.1.0 = bar 5), 960 ticks per quarter note. Errors come back as a tool result, never as a crash.

ToolPurpose
inspect_projectWhole project: tempo, time signature, locators, markers, tracks with events
get_notesNotes of a MIDI part
new_project · open_project · save_projectCreate, open and save project files
import_audio · import_midiAudio file onto a track, standard MIDI file as MIDI tracks
export_mixdown · export_midiLocator range as 24-bit WAV, FLAC or AIFF; MIDI file
add_track · set_trackAdd a track; name, fader, pan, mute, solo
create_part · add_notesCreate a MIDI part, add or replace notes
move_event · split_event · delete_eventsMove, copy, split and delete events
set_tempo · add_marker · set_locatorsTempo and time signature, markers, locators
undo · redoHistory – every edit is one undo step
transportOnly with --connect: play, stop, set cursor
ui_screenshot · ui_inspect · ui_clickOnly with --connect: view the window, read and click controls

Security

The agent stays in its folders.

The server only starts with defined read and write folders. Every path is checked before anything is opened or saved.

  • {{icon:check}}--automation-read-root: reading is allowed here
  • {{icon:check}}--automation-write-root: writing is allowed here
  • {{icon:check}}Control channel on 127.0.0.1 only, with a new token on every start
  • {{icon:check}}An unknown flag is an error – never an open server
Limits of this version

Headless mode loads no plugins and has no playback or recording; the mixdown renders without plugins. Key presses, dragging and scrolling are still missing, as are mixer routing, sends, inserts and automation as tools. Details in the MCP documentation.
