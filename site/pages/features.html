Features

A complete studio in one window.

StudioCraft follows a proven DAW workflow: create tracks, record, edit, mix and export. Here is everything that already works today.

01

Project window

On the left, the inspector with the settings of the selected track; next to it the track list and the event display with ruler. At the bottom, the lower zone with mixer, piano roll and sample editor. Transport bar with F2, mixer window with F3.

Exactly one tool is active; the number keys select it directly:

KeyToolUsed for
1Object selectionSelect, move and resize events
2Range selectionTime range across several tracks
3SplitSplit an event at the position
4GlueJoin an event with the next one
5EraseDelete events
6ZoomZoom in and out
7MuteMute or unmute events
8DrawCreate parts and notes
9PlayListen from a position, scrub
0Time warpDrag beats onto the grid
02

Track types

Every track has a type and its own colour, which new events and the mixer channel inherit. The track header shows mute, solo, record enable, monitor and automation at a glance.

  • Audio
  • Instrument
  • MIDI
  • Group
  • FX channel
  • Folder
  • Marker
  • Tempo & time signature
03

Recording

Audio and MIDI are recorded straight into the tracks. In cycle mode, several takes stack on top of each other, and you assemble the best version from them by comping.

  • Cycle takes
  • Punch in / punch out
  • Count-in
  • Take lanes
  • Comping
  • MIDI recording
04

Editors

The piano roll shows MIDI notes on a keyboard with velocities below. Quantize aligns notes to the grid, the sample editor works directly on the waveform, and fade and crossfade editors shape transitions.

  • Piano roll
  • Quantize
  • Sample editor
  • Fade editor
  • Crossfade editor
  • List editor
05

Mixer

Every channel has an input stage, pre-filters, EQ, pre- and post-fader inserts and sends. Solo modes, peak hold, saved mixer views and input and output busses round off the mixer.

  • Input stage
  • Pre-filter
  • EQ
  • Inserts pre/post
  • Sends
  • Solo modes
  • Peak hold
  • Mixer views
  • Busses
06

Automation & tempo

Parameters can be read and written as curves. The tempo track supports fixed and variable tempos as well as time signature changes. Plugin delay compensation keeps every track in time.

  • Automation read/write
  • Tempo track
  • Time signatures
  • Delay compensation
07

Plugins

StudioCraft loads instruments and effects in CLAP and LV2 format. Their state is saved with the project. The plugin scan runs in separate processes: if a plugin crashes, it is blocked instead of taking the program down with it.

  • CLAP
  • LV2
  • Instruments
  • Effects
  • safe plugin scan

LV2 requires lilv to be installed; without lilv, LV2 plugins are simply not offered.

08

Export

Render tracks in place, freeze them, export stems or save the whole song as a mixdown.

  • Render in place
  • Freeze track
  • Stem export
  • WAV
  • FLAC
  • AIFF
  • MIDI export
09

Projects

A project is a folder containing a .studiocraft file in an open JSON format plus the audio files. Autosave and crash recovery protect your work. Dark and light appearance can be switched.

  • open JSON format
  • autosave
  • crash recovery
  • dark & light theme
