Audio engine

Real-time audio, Rust all the way through.

Transport, mixing, routing, recording, MIDI and export run in a dedicated engine. It talks to your computer's audio system and hosts your plugins.

Audio hosts

The right audio system for each platform.

Choose the host with --audio-host <name>. studiocraft --list-hosts shows what is included in a given build.

SystemAudio hosts
LinuxPipeWire (default), ALSA; JACK with --features jack
WindowsWASAPI (shared mode); ASIO only in your own build with --features asio
macOSCoreAudio; JACK with --features jack
FreeBSDALSA via OSS; PipeWire and JACK as features
WebWeb Audio, selected automatically

Plugins

CLAP and LV2 – hosted reliably.

Instruments & effects

CLAP instruments and inserts as well as LV2 plugins with parameter controls. Each plugin's state is saved with the project.

Scanning in child processes

The plugin scan runs in separate processes. If a plugin crashes during the scan, it is blocked – StudioCraft keeps running.

Plugin windows

Plugin interfaces float as their own windows everywhere; on X11 they can be embedded. VST3 and AU are still open.

Architecture

Clearly separated building blocks.

Rust only, no Electron or Tauri. The interface uses egui/eframe, audio input and output go through cpal.

PathPurpose
apps/studiocraftDesktop app (eframe/egui)
apps/studiocraft-cliCommand line for tests and scripts, with MCP server
crates/projectProject model, edits, tempo map, versioned file format
crates/engineReal-time audio: transport, mixing and routing, recording, MIDI, export
crates/plugin-hostPlugin hosting for CLAP and LV2
crates/graphSignal graph helpers
crates/uiProject window, mixer, editors, menus, theme, settings
crates/automationMCP server for AI agents

Build it yourself

Start from source.

Requires Rust 1.85 or newer. On Linux you also need the ALSA and PipeWire development files and clang.
