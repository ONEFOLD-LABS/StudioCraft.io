Record, arrange and mix music.

StudioCraft is a cross-platform audio workstation written in Rust. A familiar DAW workflow – free and open source.

Features

Everything a song needs.

From the first track to the finished mixdown – in one project window that feels like a studio.

Project window

Inspector, track list, event display and a lower zone with mixer, piano roll and sample editor. Tools sit on keys 1–0.

Recording

Audio and MIDI with cycle takes, punch in/out, count-in, take lanes and comping.

Mixer

Channel strips with input stage, pre-filters, EQ, pre- and post-fader inserts, sends, solo modes and peak hold.

Editors

Piano roll, quantize, sample editor, plus fade and crossfade editors.

Automation

Read and write, tempo track and time signatures, plugin delay compensation.

Plugins: CLAP & LV2

Instruments and effects, with their state saved in the project. Scanning runs in separate processes and blocks crashing plugins.

Export

Render in place, freeze tracks, stem export and audio mixdown to WAV, FLAC or AIFF.

Open project format

Project folders in an open JSON format, with autosave and crash recovery.

Dark & light

Dark and light appearance in wine red, switchable under View → Appearance.

AI agents

An AI agent as your studio assistant.

Through the built-in MCP server, agents such as Claude Code, Codex or Cursor create projects, import audio, place notes and render the mixdown – headless or in the running app.

How the MCP server works{{icon:arrow}}
Terminal
studiocraft-cli mcp \
  --automation-read-root ~/Music/Samples \
  --automation-write-root ~/Music/Projects
Control the running app
studiocraft --control 7850
studiocraft-cli mcp --connect 7850

Open source

Built clean-room.

StudioCraft is an independent, private project. Its workflow is described in its own specification; code, graphics and text do not come from other products.

  • {{icon:check}}Pure Rust with egui – no Electron, no Tauri

  • {{icon:check}}Changes reach main only through pull requests
