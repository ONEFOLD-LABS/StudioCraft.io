Installation

Good to know.

  • {{icon:check}}deb and rpm register .studiocraft projects and recommend lilv for LV2 plugins.
  • {{icon:check}}The Windows MSI adds a Start menu entry and opens WAV, FLAC, AIFF and MP3 via “Open with”.
  • {{icon:check}}On macOS, drag the app from the DMG into “Applications”.
  • {{icon:check}}The Flatpak finds plugins from the Flathub Linux audio extensions.
Code signing

Windows and macOS packages will be signed (macOS also notarized) once the certificates are in place. Until then they are unsigned or ad-hoc signed – verify the files with SHA256SUMS.txt.

Checksum on Linux and macOS
sha256sum -c SHA256SUMS.txt --ignore-missing

From source

Build it yourself.

With Rust 1.85 or newer. On Linux you also need the ALSA and PipeWire development files and clang.
